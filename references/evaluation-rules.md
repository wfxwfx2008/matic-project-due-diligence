# 评价、状态与红旗规则

## 八维度五星评级

每项独立评级，不计算机械平均分。临床意义与技术创新性是优先关注项，但不能抵消重大合规或真实性问题。证据不足时标注“暂不评分”，并写明缺少什么。

| 星级 | 含义 |
|---|---|
| ★★★★★ | 公开证据充分，优势显著且与项目阶段相匹配，关键风险可控 |
| ★★★★☆ | 总体较强，存在少量可验证或可整改问题 |
| ★★★☆☆ | 具备一定价值，但关键证据、差异化或执行条件不足 |
| ★★☆☆☆ | 主要依据项目方陈述，存在明显短板或较高不确定性 |
| ★☆☆☆☆ | 核心逻辑不成立、证据相反或存在难以解决的结构性问题 |

### 维度判断重点

- **临床需求**：痛点强度、目标人群、现行路径、临床增益、使用场景、付费和采购。
- **政策与战略价值**：是否符合明确政策风向、监管趋势、国产替代或重点人群需求；不以泛化政策口号加分。
- **技术先进性**：全球对标、关键指标、验证条件、创新类型、可复制性和相对替代方案的真实增益。
- **知识产权与壁垒**：核心权利归属、覆盖度、法律状态、技术秘密、数据与工程积累、可绕开性。
- **市场与竞争**：市场边界、竞争格局、替代方案、支付和采购、可实现份额及测算可靠性。
- **团队能力**：技术临床匹配、结构完整性、历史兑现、诚信、核心人员持股和至少一人全职运营。
- **产业化可行性**：产品成熟度、工艺、供应链、成本、质量、渠道、资金用途和规模化路径。
- **注册与临床转化可行性**：产品分类、注册路线、临床证据、质量体系、周期成本、伦理和合规。

## 尽调状态

- **初筛中**：已接收材料，尚未形成稳定判断。
- **待项目方补充**：关键结论取决于项目方补证。
- **待专家论证**：需要临床、技术或注册专家判断才能推进。
- **建议推进**：价值与可行性较强，可进入下一轮。
- **有条件推进**：满足明确前置条件后可推进。
- **暂缓推进**：当前不投入实质资源，等待外部条件或证据变化。
- **不建议推进**：初筛或当前证据下不值得进入下一轮。
- **终止推进**：已补充沟通或专家论证，决定不再投入资源。

## 一票否决

以下为默认红旗，需结合项目阶段和证据判断：

1. 核心临床需求不成立，或可被成熟低成本方案充分替代。
2. 技术指标缺乏有效对照，测试条件刻意避开真实场景，且补证后仍无法支持核心主张。
3. 核心数据无法追溯、疑似选择性展示或存在真实性问题。
4. 团队履历、专利、注册进展等关键信息失实。
5. 产品注册或临床应用路径明显不可行。
6. 市场规模严重夸大，付费方和采购路径均不成立。
7. 核心技术依赖外部单位，项目主体没有所有权、稳定许可或实际控制权。
8. 关键部件、材料或工艺受制于人，成本结构无法支撑商业化，且无可行替代。
9. 竞品高度成熟，而项目没有可验证的差异化。
10. 核心团队无人愿意全职到公司运营。
11. 创始人诚信、成果归属或股权安排存在无法消除的重大问题。

### 触发等级

- **确认触发**：有可靠公开证据或补充材料确认。明确写出“触发一票否决”，列事实、证据与影响，原则上不建议推进。
- **疑似触发**：存在重大疑点但材料不足。暂停实质推进，列出解除疑点必须获得的证据。
- **重大前置条件**：问题可通过补证、整改、许可、人员全职或架构调整解决。明确完成条件和验证方式。

一票否决不能仅因早期项目尚未完成注册、量产或融资而触发。要判断其路径是否合理、证据是否匹配当前阶段、团队是否有能力补齐。

## 财政资金与合作适配提示

医创中心原则上支持新设项目公司，不直接投资已有融资和估值的公司。对成熟公司可提示评估业务拆分、新设项目公司、核心资产注入和成果许可等可能性。该适配性单列说明，不等同于项目技术价值评价，也不得当作法律、审计或国资评估结论。
