# 评价、状态与红旗规则

## 三项上位综合评级

报告第一部分分别评价战略性、先进性和可行性，每项给1—5星或“暂不评分”。三项属于第二部分八维度评级及外部证据的综合呈现，不机械取平均值，不计算项目总分或综合星级。项目价值与医创中心合作适配性分开：三项只评价项目本身，中心适配性单列在AI综合研判意见和合作参考建议中。

| 星级 | 战略性 | 先进性 | 可行性 |
|---|---|---|---|
| ★★★★★ | 临床或产业战略价值突出，需求长期存在且政策方向明确 | 达到全球领先或形成显著原创突破，有较强证据支持 | 转化路径清晰，关键条件基本具备，重大风险可控 |
| ★★★★☆ | 战略价值较强，但影响范围或政策确定性略有限 | 达到国际先进或国内稀缺水平，仍有少量关键证据待补 | 整体可行，存在可通过补证或资源补齐解决的问题 |
| ★★★☆☆ | 需求真实但战略重要性一般，或未来可能受到替代 | 有一定创新和差异化，但关键优势尚未充分验证 | 路径基本成立，但注册、团队、权属或产业化仍有重要缺口 |
| ★★☆☆☆ | 战略意义主要来自项目方表述，实际需求或政策支撑较弱 | 以跟随、组合或局部改进为主，差异化不足 | 存在多项重大不确定性，需要显著调整才能推进 |
| ★☆☆☆☆ | 核心需求不成立或与明确政策、临床趋势相悖 | 核心技术主张不成立或已被成熟方案明显超越 | 存在难以解决的注册、技术、权属、团队或产业化障碍 |

### 综合维度与详细维度的关系

| 综合维度 | 主要参考内容 |
|---|---|
| 战略性 | 临床需求、政策与战略价值，并考虑未来治疗或诊断方案对需求持续性的影响 |
| 先进性 | 技术先进性、知识产权与壁垒、市场竞争中的技术差异化及跨适应证拓展证据 |
| 可行性 | 团队能力、产业化可行性、注册与临床转化可行性，并兼顾市场和商业闭环 |

采用阶段适配原则。战略性不因项目早期而降低；先进性坚持全球对标，但证据要求与研发阶段相匹配；可行性不按“距离上市还有多远”简单评分，而是判断从当前阶段走向产品化的路径是否可信。早期本身不是低分理由，但技术路线、注册路径、成果权属或核心团队投入存在结构性障碍时应明显降级。

公开证据严重不足、无法形成负责任判断时标注“暂不评分”，并说明缺少的材料或验证。第一部分不重复八维度评分图表。AI综合研判意见承担最终结论，采用“状态＋拟进入的具体阶段”，不得用三项评级或八维度评级的平均值替代决策。

## 八维度五星评级

每项独立评级，不计算机械平均分。临床意义与技术创新性是优先关注项，但不能抵消重大合规或真实性问题。证据不足时标注“暂不评分”，并写明缺少什么。

| 星级 | 含义 |
|---|---|
| ★★★★★ | 公开证据充分，优势显著且与项目阶段相匹配，关键风险可控 |
| ★★★★☆ | 总体较强，存在少量可验证或可整改问题 |
| ★★★☆☆ | 具备一定价值，但关键证据、差异化或执行条件不足 |
| ★★☆☆☆ | 主要依据项目方陈述，存在明显短板或较高不确定性 |
| ★☆☆☆☆ | 核心逻辑不成立、证据相反或存在难以解决的结构性问题 |

### 维度判断重点

- **临床需求**：痛点强度、目标人群、现行路径、临床增益、使用场景、付费和采购，并考虑已获批、临床阶段和可信临床前潜在方案对需求持续性的影响。
- **政策与战略价值**：是否符合明确政策风向、监管趋势、国产替代或重点人群需求；不以泛化政策口号加分。
- **技术先进性**：全球对标、关键指标、验证条件、创新类型、可复制性和相对竞品及替代路线的真实增益；明确项目相对优势、相对劣势、可比性和所需验证，不得用不可直接比较的数据加分。跨适应证拓展须按证据等级判断，不能因理论应用面广而直接加分。
- **知识产权与壁垒**：核心权利归属、覆盖度、法律状态、技术秘密、数据与工程积累、可绕开性。
- **市场与竞争**：产品层与路线层竞争格局、相对优劣势及其证据强度、替代威胁、支付和采购；五层市场模型的边界、代理数据可靠性、敏感性，以及项目销售与SOM、产能和医院准入的一致性。
- **团队能力**：技术临床匹配、结构完整性、历史兑现、诚信、核心人员转化意愿、明确负责人及分阶段全职安排，并关注其对外持股、任职或其他利益关联是否造成投入、成果归属或同业竞争冲突。初筛阶段不以尚无人全职直接扣至否决；项目公司设立或正式转化启动前，应形成至少一名全职经营负责人。
- **产业化可行性**：产品成熟度、工艺、供应链、成本、质量、渠道、资金用途和规模化路径。
- **注册与临床转化可行性**：产品分类、注册路线、临床证据、质量体系、周期成本、伦理和合规。

## 尽调状态

- **初筛中**：已接收材料，尚未形成稳定判断。
- **待项目方补充**：关键结论取决于项目方补证。
- **待专家论证**：需要临床、技术或注册专家判断才能推进。
- **建议推进**：价值与可转化性较强，可进入下一阶段成果转化流程。
- **有条件推进**：满足明确前置条件后，可进入下一阶段成果转化流程。
- **暂缓推进**：当前不启动实质性成果转化动作，等待外部条件或证据变化。
- **不建议推进**：初筛或当前证据下不值得进入下一阶段成果转化流程。
- **终止推进**：已补充沟通或专家论证，决定不再进入后续成果转化流程。

报告第一部分的尽调建议须在上述状态后说明具体下一阶段，例如“有条件推进至临床与注册专家论证阶段”或“建议推进至第三方性能验证阶段”。“建议推进”不代表建议投资、设立项目公司或投入产业化资源。

## 一票否决

以下为默认红旗，需结合项目阶段和证据判断：

1. 核心临床需求不成立，或可被成熟低成本方案充分替代。
2. 技术指标缺乏有效对照，测试条件刻意避开真实场景，且补证后仍无法支持核心主张。
3. 核心数据无法追溯、疑似选择性展示或存在真实性问题。
4. 团队履历、专利、注册进展等关键信息失实。
5. 产品注册或临床应用路径明显不可行。
6. 市场规模严重夸大，付费方和采购路径均不成立。
7. 核心技术依赖外部单位，项目主体没有所有权、稳定许可或实际控制权。
8. 关键部件、材料或工艺受制于人，成本结构无法支撑商业化，且无可行替代。
9. 竞品高度成熟，而项目没有可验证的差异化。
10. 在项目公司设立或正式转化启动前，核心团队仍无明确转化投入承诺，且无法形成至少一名全职经营负责人及可执行的人员安排。早期初筛阶段尚无人全职不单独触发本项。
11. 创始人诚信、成果归属或股权安排存在无法消除的重大问题。

### 触发等级

- **确认触发**：有可靠公开证据或补充材料确认。明确写出“触发一票否决”，列事实、证据与影响，原则上不建议推进。
- **疑似触发**：存在重大疑点但材料不足。暂停实质推进，列出解除疑点必须获得的证据。
- **重大前置条件**：问题可通过补证、整改、许可、人员全职或架构调整解决。明确完成条件和验证方式。

一票否决不能仅因早期项目尚未完成注册、量产、融资或尚未形成全职经营团队而触发。要判断其路径是否合理、证据是否匹配当前阶段、团队是否具有明确转化意愿和补齐能力。

## 成果转化定位与资源边界

医创中心定位为早期科技成果转化平台，不开展成熟项目投资。已有融资、估值和稳定经营基础的成熟项目原则上不作为中心投资对象；只有存在独立、可确权且可转让的新成果包时，才评估成果许可、转让或新设项目公司的可行性，不得为迎合合作条件建议形式化拆分。该适配性单列说明，不等同于项目技术价值评价，也不得当作法律、审计或国资评估结论。

不得预设中心具备大规模或专业化硬件支撑。中心现有普通生物实验室和洁净细胞房，在项目公司需要且条件适用时，可按技术服务方式提供使用。动物实验、GMP中试、专用设备、型式检验及其他专业平台，应单列外部获取路径、费用、周期、资质和责任边界；不能把资源撮合写成中心已承诺提供。
